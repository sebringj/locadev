Built for real client apps

Same SDKs you use in production — Azure Storage, Service Bus, OpenAI client, PGlite SQL, Redis, Topaz RBAC, and more behind profiles.

⚙ Env-only swap

Consumer contract is connection strings and endpoints. Move to a real cloud later with a value swap.

☁ Azure surface

Azurite, Service Bus emulator, Foundry-shaped OpenAI bridge, optional Cosmos, AI Search, Key Vault.

⬡ AWS surface

MiniStack on :4566 for S3-compatible local testing with seed data and boto3 endpoint_url.

▣ Pick profiles

Core stack is lean; spin up teams, slack, mail, search, cosmos, and more only when you need them.

◆ Fake channels

Fake Teams, Slack, and SendGrid with ways to see messages — UI, JSON capture, test hooks.

◎ Demos & playground

CLI demos plus a DaisyUI web playground that exercises blob, bus, bridge, PGlite, Redis, and Topaz.

Quick start

macOS / Linux with Docker Compose v2. Full detail lives in the repo README.

Clone & env

cp .env.example .env

Bring up core

make up && make verify

Point your app

Copy values from sandbox.env.example into the client repo.

Honest by design

locadev is an interim local stand-in, not a full isolated subscription. Topaz ≠ Entra RBAC; PGlite ≠ multi-writer Postgres; AI Search filters are partial. Limitations are documented so you find them here — not at runtime in staging.
